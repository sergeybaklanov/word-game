GET + object + past participle (causative)

Use get + object + V3 to say that you arrange for something to be done — you don't do it yourself. This is the informal equivalent of have something done.

+
Subject + get + object + past participle
✎
"I got my car repaired." (someone else repaired it for me)
✎
"She's getting her hair cut tomorrow." (at the hairdresser)
✎
Compare: "have + object + V3" — same meaning, more formal: "I had my car repaired."
GET + object + to-infinitive (causative)

Use get + object + to + V to say you persuade or arrange for someone to do something. Unlike make/have, get uses a to-infinitive.

+
Subject + get + person + to + V
✎
"I can't get him to listen." (can't persuade him)
✎
"She got her brother to fix the computer." (persuaded him to)
✎
Compare: make/have + object + bare infinitive (no "to"): "She made him apologise."
✓
GET in passive constructions Get-passive is an informal alternative to be-passive. It often implies the subject is responsible or that the event was unexpected: "He got fired." (informal) vs "He was fired." (neutral). Common get-passive: get paid, get hurt, get killed, get promoted, get arrested, get married, get divorced.
